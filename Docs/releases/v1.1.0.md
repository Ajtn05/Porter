# Porter v1.1.0

Porter v1.1.0 makes browsing an Android phone more familiar to Finder users,
with commands for the active pane, folder history, and native list columns.

## Download and install

Requires macOS 14 or later. `Porter-1.1.0-macos-universal.zip` contains native
Apple silicon and Intel binaries. Unzip it and move `Porter.app` to Applications.
Start Porter before connecting the phone, then select File Transfer mode on
Android. USB debugging is optional; enabling it gives Porter the ADB transport.
Existing view, sorting, hidden-file, and preview preferences are preserved.

**Distribution status:** the prepared package is ad hoc signed and is not
notarized. macOS may block a downloaded copy. Developer ID signing and
notarization remain pending. This draft is for review and testing.

## What's new

- Commands target the active Mac or Android pane, identified by an accent
  underline in its header. New Folder now works on the phone as well as the Mac.
- Finder keyboard behavior: Return renames, Command-Down opens the selection,
  Command-Up opens the parent folder, and Shift-Command-N creates a folder.
  Space and Command-Y invoke Quick Look. Command-1 and Command-2 switch the
  active pane between icons and list; Shift-Command-P toggles its preview.
- Independent Back and Forward buttons and Command-[ / Command-] shortcuts
  restore each folder's selection and scroll position. Phone history resets
  when changing devices or storage volumes. Failed folder loads leave history
  unchanged, and outdated navigation requests cannot cross storage volumes.
- Refresh preserves selections of files still present, including after a
  completed transfer. Deleted files are removed from the selection.
- Native, resizable Name, Date Modified, Size, and Kind columns. Click a header
  to sort; each pane saves its own column widths and sort preferences. List
  selection supports native range selection and type-to-select behavior.
- List dragging supports the Mac selection and remote selections, with folders
  as precise drop destinations. Browser commands are scoped to the main browser
  and do not act on files while a text field or sheet is active.
- Release packaging uses version-matched notes and requires committed source,
  so binaries, the source archive, and build metadata identify the same revision.

ADB and MTP transfer capabilities remain available, with bundled Android
platform-tools 37.0.1 ADB and upstream notices. No separate ADB installation is
required.

## Validation

The preparation passed 15 browser state checks, 6 checks against the app model,
and all 184 PorterKit tests in 22 suites. The universal Release app and embedded
Finder extension passed bundle, architecture, and local signature checks.
Validation used command-line checks without launching Porter or contacting a
phone. The new desktop interactions still require runtime validation.

## Known limits

- Finder integration remains an experimental, read-only File Provider. Signed
  Finder registration and real-device downloads remain unvalidated; ad hoc
  signing may not provide usable App Group access. Use Porter's browser for
  transfers.
- MTP transfers run one at a time, restart after interruption, and are marked
  unverified because MTP cannot compute a device-side checksum. Modification
  dates and storage-space reports are best effort.
- If another process owns the phone's MTP interface, reconnect it with Porter
  already running. Phone compatibility and sustained-load testing remain limited.
- Copy/paste between panes, phone-wide search, column/gallery views, and
  supported writable Finder access are not included in this release.
- No Wi-Fi transfers, photo import, watched folders, or APK sideloading.
