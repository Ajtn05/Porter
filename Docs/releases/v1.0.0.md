# Porter v1.0.0

Porter's first USB release for macOS brings Android file transfers to a native
dual-pane browser. No account or Android companion app is required.

## Download and install

Requires macOS 14 or later. `Porter-1.0.0-macos-universal.zip` includes native
Apple silicon and Intel binaries. Unzip it and move `Porter.app` to Applications.
Start Porter before connecting the phone, then select File Transfer mode on
Android. USB debugging is optional; enabling it gives Porter the ADB transport.

**Distribution status:** this draft's app is ad hoc signed and is not notarized.
macOS may block a downloaded copy. Developer ID signing and notarization are
pending before the supported public release. The draft is for review and testing.

## Included

- USB discovery with automatic preference for ADB and fallback to direct MTP.
- Browse internal and removable storage, copy files in both directions, create
  folders, rename, move within a volume, and delete.
- Transfer queue, conflict handling, filename sanitizing, and available
  free-space and FAT32 file-size checks.
- ADB resume, SHA-256 verification, modification-time preservation, and small-file batching.
- Independent Mac and Android views, sorting, hidden-file settings, resizable
  preview sidebars, thumbnails, and Quick Look.
- Native MTP thumbnails with bounded optional full-file fallbacks.
- Bundled Android platform-tools 37.0.1 ADB, including upstream notices. No
  separate platform-tools installation is needed.
- The Xcode 26.6 thumbnail cancellation compile fix.

## Known limits

- Finder integration is an experimental read-only File Provider. Signed Finder
  registration and real-device downloads remain unvalidated, and the ad hoc
  build may not have usable App Group access. Use Porter's browser for transfers.
- MTP transfers run one at a time, restart after interruption, and are marked
  unverified because MTP cannot compute a device-side checksum. Modification
  dates and space reporting are best effort.
- If another process owns the phone's MTP interface, reconnect it with Porter
  already running. Phone compatibility and sustained-load testing remain limited.
- No Wi-Fi transfers, photo import, watched folders, or APK sideloading.
- This release preparation uses command-line checks. New preview layouts and
  Finder behavior have not been validated through desktop UI testing.
